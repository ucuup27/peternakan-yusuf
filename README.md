# 🐰 Smart Farm Management System

Aplikasi manajemen inventaris peternakan berbasis web untuk memantau data ternak, menghitung umur otomatis, dan pencatatan riwayat penjualan/kematian.

## 📸 Screenshot Dashboard![1000308904](https://github.com/user-attachments/assets/4b47c265-3068-4049-a6bb-daa86432615c)

## 🚀 Fitur Utama
* **Dashboard Monitoring:** Tampilan modern dan responsif (Bootstrap 5).
* **Auto Age Calculator:** Menghitung umur kelinci real-time.
* **Manajemen Arsip:** Data tidak hilang (Soft Delete) saat terjual/mati.
* **Keamanan Tinggi:** Login Database, Anti-SQL Injection, & Anti-XSS.

## 🛠️ Teknologi (Tech Stack)
* **OS:** Linux Mint (Server)
* **Web Server:** Nginx & PHP 8.3
* **Database:** MariaDB
* **Keamanan:** UFW Firewall, Fail2Ban, SSL.

## 🔧 Cara Install
1. Clone repo ini.
2. Import file `database.sql` ke MariaDB.
3. Sesuaikan koneksi di `kelinci.php`.
